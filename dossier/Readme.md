# Микросервис Кредитное Досье (Dossier)

## 📖 Описание проекта

Микросервис **Dossier** (Кредитное Досье) отвечает за формирование документов и асинхронную отправку email-уведомлений клиентам на различных этапах оформления кредита. 

Сервис работает исключительно в фоновом режиме, прослушивая события (сообщения) из брокера сообщений **Apache Kafka**, которые публикуются микросервисом **Deal** (Сделка). Получив сообщение, Dossier формирует текст письма (или документ) и отправляет его на указанный электронный адрес клиента.

## 📨 Интеграция с Kafka (Consumer)

Микросервис выступает в роли подписчика (Consumer) и ожидает сообщения в формате DTO `EmailMessage`. 

В приложении настроены слушатели (listeners) для **6 Kafka-топиков**, каждый из которых соответствует определенному этапу кредитного конвейера:

1. **`finish-registration`** — Уведомление о предварительном одобрении заявки с просьбой завершить оформление (прислать полные данные).
2. **`create-documents`** — Уведомление о финальном одобрении кредита со ссылкой на запрос формирования документов.
3. **`send-documents`** — Отправка клиенту сформированных кредитных документов и ссылки на запрос согласия с условиями.
4. **`send-ses`** — Отправка клиенту секретного кода (ПЭП) для подписания документов.
5. **`credit-issued`** — Финальное уведомление об успешной выдаче кредита.
6. **`statement-denied`** — Уведомление об отказе в выдаче кредита по результатам скоринга.

## 🚀 Требования и Запуск

**Требования к окружению:**
* **Java 17/21+** и **Maven**.
* Работающий кластер **Apache Kafka** и **Zookeeper** (рекомендуется запуск через `docker-compose`).
* SMTP-сервер для тестирования отправки писем (рекомендуется использовать **Mailcatcher** в Docker: `docker run -d -p 1080:1080 -p 1025:1025 sj26/mailcatcher`).

**Инструкция по запуску:**

1. Склонируйте репозиторий и перейдите в папку микросервиса:
   ```bash
   git clone <url_репозитория>
   cd <имя_проекта>/dossier
   ```

2. В файле `src/main/resources/application.yml` укажите актуальные настройки:
   * URL брокера Kafka (`spring.kafka.bootstrap-servers`).
   * Настройки SMTP-сервера (для локального тестирования через Mailcatcher укажите `host: localhost`, `port: 1025`).

3. Соберите проект:
   ```bash
   mvn clean package
   ```

4. Запустите приложение:
   ```bash
   java -jar target/dossier-0.0.1-SNAPSHOT.jar
   ```

## 🧪 Тестирование и Логирование

* **Логирование:** Обработка каждого входящего сообщения логируется (`Slf4j`). Логируются топик, данные адресата и статус отправки письма (входные данные на уровне `INFO`, промежуточные шаги формирования письма на уровне `DEBUG`).
* **Тестирование:** Логика формирования писем и работа Kafka-консьюмеров покрыта unit-тестами с использованием JUnit 5 и Mockito.
